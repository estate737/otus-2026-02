# Инструкция для сотрудников сервисного центра

## Кто что видит

| Роль | Доступ |
|---|---|
| Механик | только свои заказ-наряды и своих клиентов |
| Менеджер | все заказ-наряды, гараж клиентов, подача заявок на закупку |
| Закупщик и начальник отдела закупок | заявки на закупку |
| Директор | всё |

## Менеджер: приём автомобиля в ремонт

### 1. Завести клиента и его машину
1. CRM -> Контакты -> «Создать», заполнить имя и телефон.
2. Раздел «Автомобили» -> «Создать»: Марка, Модель, Госномер, Год, Цвет, Пробег, VIN,
   в поле «Клиент» выбрать контакт.
   Машина заводится один раз, дальше по ней просто создаются заказ-наряды.

### 2. Создать заказ-наряд
1. CRM -> Сделки -> воронка «Сервисное обслуживание» -> «Создать».
2. В поле **«Автомобиль»** выбрать машину из списка (поиск по марке или номеру).
3. Название можно не заполнять: подставится автоматически в виде
   «Фамилия Имя, Марка Модель, Госномер».
4. Запчасти добавляются в блоке товаров: выбираются из каталога, указывается количество.
5. Сохранить.

Если по этой машине уже есть незакрытый заказ-наряд, система не даст создать новый
и покажет, какой заказ-наряд нужно сначала завершить. Ответственный за тот заказ-наряд
получит уведомление.

### 3. Вести ремонт по стадиям
Приемка -> Диагностика -> Ожидание запчастей -> Ремонт -> Проверка -> Завершено.
Стадия меняется перетаскиванием карточки в канбане.

## Гараж клиента: история по машине

1. Открыть карточку контакта.
2. Вкладка **«Гараж»**: карточки всех машин клиента с маркой, госномером, годом,
   цветом и пробегом.
3. Нажать на карточку машины: откроется окно с историей всех обращений.
   В окне по каждому заказ-наряду видно название, дату создания, стадию,
   ответственного (ссылка на профиль), сумму и список запчастей.

## Заявка на закупку запчастей

### Подать заявку (любой сотрудник)
1. CRM -> «Заявки на закупку» -> «Создать».
2. Указать запчасти и количество, сохранить.
3. Заявка уходит на согласование закупщику. Если все закупщики отсутствуют,
   заявка направляется начальнику отдела закупок.

### Согласовать (закупщик)
- **Одобрить**: остатки запчастей увеличиваются на указанное количество,
  заявка переходит в «Выполнено», инициатор получает уведомление.
- **Отклонить**: указывается причина, остатки не меняются, заявка переходит
  в «Отклонено», инициатор получает уведомление с причиной.

## Остатки запчастей

- Запчасти и их количество хранятся в каталоге товаров: CRM -> Товары.
- Раз в сутки система сама сверяет остатки с внешним сервисом складов.
- Если запчасть закончилась, система автоматически закупает 10 штук:
  создаёт заявку, пополняет остаток, закрывает заявку и уведомляет закупщика.
- Журнал обменов: `local/logs/stock_sync.log`.

## Частые вопросы

**Не дают создать заказ-наряд.**
По машине есть незавершённый ремонт. Найдите его по номеру из сообщения,
завершите или отмените, после этого создавайте новый.

**Не вижу чужие заказ-наряды.**
Механик видит только свои. Полный список доступен менеджеру и директору.

**Машины нет в списке при создании заказ-наряда.**
Её ещё не завели. Раздел «Автомобили» -> «Создать», указать клиента.

**Запчасть закончилась, а заявку никто не создавал.**
Система закупает такие позиции сама, уведомление приходит закупщику.

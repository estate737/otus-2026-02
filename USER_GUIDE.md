# Инструкция для сотрудников сервисного центра

## Кто что видит

| Роль | Доступ | С чего начать |
|---|---|---|
| Механик | свои заказ-наряды, клиенты и автомобили из них | CRM -> Сделки |
| Менеджер | все заказ-наряды, клиенты и гараж, подача заявок на закупку | CRM -> Сделки |
| Закупщик и начальник отдела закупок | заявки на закупку | левое меню -> «Заявки на закупку» |
| Директор | вся CRM: обе воронки сделок, лиды, компании, настройки | CRM |

Раздел сделок сразу открывает воронку «Сервисное обслуживание».

## Вход в портал

Портал `https://cr677203.tw1.ru/`, вход по логину и паролю сотрудника.
В левом меню раздел **CRM**: «Сделки» - заказ-наряды воронки «Сервисное обслуживание»,
«Контакты» - клиенты, «Автомобили» - справочник машин, «Заявки на закупку» - закупки,
«Товары» - каталог с разделом «Запчасти».

## Менеджер: приём автомобиля в ремонт

### 1. Завести клиента и его машину
1. CRM -> Контакты -> «Создать», заполнить имя и телефон.
2. Раздел «Автомобили» -> «Создать»: Марка, Модель, Госномер, Год, Цвет, Пробег, VIN,
   в поле «Клиент» выбрать контакт.
   Название машины собирается само: «Марка Модель Госномер».
   Машина заводится один раз, дальше по ней создаются заказ-наряды.

### 2. Принять машину в ремонт
Основной способ - из гаража клиента:
1. Открыть карточку клиента, вкладка **«Гараж»**.
2. У свободной машины нажать **«Принять в ремонт»**.
3. Откроется готовый заказ-наряд: клиент, автомобиль, название и стадия «Приемка»
   уже заполнены. Остаётся указать сумму и добавить запчасти.
4. В поле **«Ответственный»** выбрать механика: заказ-наряд появится в его канбане,
   а клиент и автомобиль станут ему доступны.

Если машина в ремонте, вместо кнопки приёма показана кнопка
«Открыть заказ-наряд №...» и текущая стадия.

Второй способ - из воронки:
1. CRM -> Сделки -> воронка «Сервисное обслуживание» -> «Создать».
2. В поле **«Автомобиль»** выбрать машину из списка (поиск по марке или номеру),
   в поле «Клиент» - её владельца.
3. Название можно не заполнять: подставится в виде «Фамилия Имя, Марка Модель, Госномер».
4. Запчасти добавляются в разделе «Запчасти и работы»: выбираются из каталога,
   указывается количество.
5. Ответственным указать механика.

Если по машине уже есть незакрытый заказ-наряд, новый создать нельзя: система покажет,
какой заказ-наряд нужно сначала завершить. Ответственный за него получит уведомление.

### 3. Вести ремонт по стадиям
Приемка -> Диагностика -> Ожидание запчастей -> Ремонт -> Проверка -> Завершено.
Стадия меняется перетаскиванием карточки в канбане.

## Механик: работа по заказ-нарядам

1. CRM -> Сделки: открывается канбан воронки «Сервисное обслуживание» с заказ-нарядами,
   где механик ответственный.
2. В карточке заказ-наряда открываются клиент и автомобиль: доступ к ним механик
   получает, когда его назначают ответственным.
3. Стадия ремонта меняется перетаскиванием карточки в канбане.
4. Во вкладке «Гараж» у клиента видны свои автомобили и история по своим заказ-нарядам.

## Гараж клиента: история по машине

1. Открыть карточку контакта, вкладка **«Гараж»**.
2. Нажать на карточку машины: откроется окно с историей всех обращений.
   По каждому заказ-наряду видно название, дату создания, стадию,
   ответственного (ссылка на профиль), сумму и список запчастей.

Менеджер и директор видят историю полностью, механик - только свои заказ-наряды.

## Заявка на закупку запчастей

### Подать заявку (сотрудник сервиса)
1. CRM -> «Заявки на закупку» -> «Создать».
2. В разделе **«Запчасти»** нажать «Добавить товар», выбрать запчасть из каталога
   и указать количество. Позиций в одной заявке может быть несколько.
3. Сохранить.

Дальше система сама:
- называет заявку по составу, например «Закупка: 2 позиции, всего 15 шт.»;
- назначает согласующего: закупщика, а если все закупщики отсутствуют,
  начальника отдела закупок;
- переводит заявку в стадию «На согласовании» и отправляет согласующему уведомление.

### Согласовать (закупщик)
Заявки открываются пунктом **«Заявки на закупку»** в левом меню.
Решение принимается сменой стадии заявки:
- **Одобрить** - перевести заявку в «Выполнено». Остатки запчастей увеличатся
  на количество из заявки, инициатор получит уведомление об успешной закупке.
- **Отклонить** - перевести заявку в «Отклонено» и заполнить поле «Причина отказа».
  Без причины отказ не сохранится. Остатки не меняются, инициатор получит
  уведомление с причиной.

Решение выполняется один раз: повторное сохранение заявки склад не пополняет.

## Остатки запчастей

- Запчасти и их количество хранятся в каталоге товаров, раздел «Запчасти».
- Раз в сутки система сверяет остатки с внешним сервисом складов.
- Если запчасть закончилась, система автоматически закупает 10 штук:
  создаёт заявку, пополняет остаток, закрывает заявку и уведомляет закупщика.
- Журнал обменов: `local/logs/stock_sync.log`.

## Частые вопросы

**Не дают создать заказ-наряд.**
По машине есть незавершённый ремонт. Найдите его по номеру из сообщения,
завершите или отмените, после этого создавайте новый.

**Где в заявке выбрать запчасти?**
В разделе «Запчасти» карточки заявки, кнопка «Добавить товар». Запчасти берутся
из каталога, вручную их вписывать не нужно.

**Поиск запчасти в карточке ничего не находит.**
Сотруднику нужна роль в правах доступа каталога товаров. Сотрудники сервиса
к ролям уже привязаны.

**Не получается отклонить заявку.**
При переводе в «Отклонено» обязательно поле «Причина отказа».

**Не вижу чужие заказ-наряды.**
Механик видит только свои. Полный список доступен менеджеру и директору.

**Механик не видит клиента или автомобиль.**
Они открываются механику, когда его назначают ответственным за заказ-наряд
этого клиента. Назначить ответственного может менеджер.

**Машины нет в списке при создании заказ-наряда.**
Её ещё не завели. Раздел «Автомобили» -> «Создать», указать клиента.

**Запчасть закончилась, а заявку никто не создавал.**
Система закупает такие позиции сама, уведомление приходит закупщику.
